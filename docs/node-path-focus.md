# 节点上下游阅读聚焦

## 产品目标

调用图用于帮助读者理解完整项目。用户点击任意节点后，界面自动强调这段逻辑从哪里来、
又会流向哪里；不需要先理解分支组，也不需要操作额外按钮。

## 聚焦规则

1. 从所选节点沿入边遍历全部上游。
2. 从所选节点沿出边遍历全部下游。
3. 所选节点、上下游节点及它们之间的真实连线保持完整对比度。
4. 其它内容降低透明度，但仍然可见、可点击和可键盘访问。
5. 点击空白画布清除选择后恢复完整对比度。

`flowKind: loop-back` 的边会继续显示并使用外侧回边路由，但不作为遍历扩散通道。这样选择
循环体节点时可以看见回环关系，又不会沿回边重新进入前序流程并扩散到整张图。

## 状态边界

- `GraphState.selected` 是唯一选择来源。
- 聚焦集合由当前可见节点和边即时计算，不持久化。
- 边类型过滤、隐藏、折叠和搜索仍先决定当前图，再计算上下游。
- 选择边只展示边详情，不触发节点上下游聚焦。
- 聚焦不改变布局、缩放、平移或持久化坐标。

## 验收

1. 选择分支内部节点时包含公共上游、当前支路和汇合后的下游，不包含兄弟支路。
2. 含循环的图可以终止遍历，回边不会让聚焦扩散到整图。
3. 聚焦前后节点和连线数量不变。
4. 画布清除、节点切换和 viewport 保持正常。
5. 普通节点/边选择、源码预览、拖拽和布局保存不退化。
