# 场景实现收敛

统一入口是主页 `/`，同时展示全部项目与内容。主阅读路径收敛为“左侧选内容，右侧阅读”：
场景 `/?scene=<slug>` 与调用图 `/?graph=<slug>` 在同一工作台切换，前进后退可恢复视图。
独立场景 HTML 仍由共享构建器生成，保留直接访问兼容，不再作为主入口的页面中转。

- 删除重复项目定位入口；项目标题本身负责展开目录，一次展开一个项目。
- 当前阅读视图列出对应调用图与具体场景，不再引导到额外目录后再次选择。
- 场景阅读组件只导入允许的静态 HTML/SVG，使用 Shadow DOM 隔离样式，无需调整安全头。
- 导航请求具有版本与取消控制，布局保存失败时留在当前内容，旧响应不能抢占新选择。
- 返回场景保留滚动位置；最近调用图的节点选择与视口在场景往返后保留。
- 模型仍分别维护调用图 JSON 和 Mermaid＋元数据，不生成页面、导航或跨图选择映射。
- 场景目录独立加载，错误可重试；工作台与独立场景继续共用构建器和校验器。
- 默认前端构建只包含正式场景和 Monaco；Atlas 使用独立 `npm run build:atlas`。

Atlas 的 React/React Flow/ELK 依赖和生成资源仍服务于实验页，继续保留在安装依赖中。
本次降低默认构建及主代码的耦合，不宣称已降低安装体积。

旧 `/api/scenarios`、scenarios/ 与 architecture-scenario.schema.json 仍有 Atlas 消费方，
保持兼容并冻结新增功能。完全退出前应迁移需保留内容、确认实验入口停用，再按契约流程
移除 API 和专用依赖。不把旧协议重新接回独立场景。

验收检查正式入口在旧 API 不可用时仍可读，Atlas 可独立构建并通过冒烟验证。

项目发现回归以 Qoreon 为样例：首页点击场景即在工作台阅读，一次点击切到对应调用图，
再返回场景时保持滚动位置；此过程不重新加载整个文档。回归覆盖连续点击、过期响应、
前进后退、保存失败、场景损坏、样式隔离和窄屏。这些检查验证阅读动线与稳定性，不代替
由陌生开发者完成的 10 分钟理解验收。
