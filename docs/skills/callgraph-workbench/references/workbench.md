# 工作台页面操作

## 进入与阅读

打开服务的 `/`，默认进入创建入口；切换“项目资料库”页签浏览项目，或点击“进入工作台”；进入调用图后，左栏按“项目目录 → 分组 → 调用图”选择。搜索只过滤目录显示，不改变删除范围。
支持 `/?graph=<slug>` 直达。工作台只有调用路径视图；同一方法可在不同调用位置显示为多个引用，不能按屏幕节点数统计唯一方法。

打开图默认选中根节点并显示源码，不自动采集。节点详情的状态与“继续采集”同行：
“待继续”表示下游尚未确认完整；“未记录下游”只表示当前查询记录没有出边，不等于业务流程结束。
折叠不会改变这些状态。“历史采集记录”按需展开，可能包含已恢复的问题，不能当作当前失败结论。
“当前路径来自…”只描述所选路径引用；点击“查看调用点”定位调用发生处，
无精确调用点的候选实现或人工关联则通过“查看关系依据”核对。不会把多态候选当作实际执行目标。
顶部四向按钮按节点的屏幕位置导航，与方向键共用逻辑。

画布聚焦且已有当前节点时，方向键按实际画布位置寻找对应方向的邻近节点，优先对齐的候选；
无候选则停留，不循环、不进入隐藏或未展开节点。多选时不跳转；输入框、源码编辑器、
菜单或缩略图聚焦时不触发节点导航。顶部四向按钮与方向键共用逻辑；空格与居中按钮将当前节点移到画布中央，保持缩放和多选。按住 Shift 拖动框选多个节点，拖动任一选中节点
可一起移动，Esc 或普通点击取消框选。框选使用独立的虚线边框，不更换右侧当前源码；
已框选节点在视口移动时仍保留，位置只在当前会话生效。操作提示和框选数量在“展示设置”中。

右键多选集合中的节点，使用“隐藏所选 / 删除所选”。入口保留并提示，同一方法的重复
调用位置按 sourceId 去重；操作覆盖这些方法的所有调用位置及独占下游，保留外部仍引用的共享下游。
隐藏仅本次有效，可“恢复隐藏”；删除先预览准确的集合影响范围，经确认一次性写入草稿，
保存才写入图文件，放弃修改可恢复。右键集合外的节点仍显示该节点的单独操作。

顶部“搜索并选择节点”合并查找与选择，支持方法名、所属类、文件名和符号 ID。
下拉结果展示方法与类/文件位置；搜索覆盖全图（包括未展开节点），临时隐藏节点不参与。
大图一次最多渲染 100 条匹配结果，可继续输入关键词缩小范围。输入与 Esc 关闭不改变画布，确认选项才定位节点。

节点按已有类型事实着色：类蓝色、接口绿色、抽象类紫色、枚举琥珀色、Record 青色；
同时保留类型文字和字母标识。选中不会改变类型底色；没有类型元数据时沿用通用配色。

默认横向；点击纵向/横向直接切换。普通点击节点或边查看详情并高亮相关路径；点击空白清除选择，拖动画布不清除。
右下缩略图用于定位大图。“适应画布”会重新适配视角，日常局部操作无需反复点击。

大图采用视口增量挂载，平移时保留已显示节点的内容；缩到概览比例时隐藏不可读的连线标签与箭头，
放大后恢复。此策略只影响绘制，不删除节点或调用关系。性能测量与边界见[大图性能专项](../../../large-graph-performance.md)。

“展示设置”控制每次展开的层数或节点数。默认层级窗口为 50 层，可自行改小；它只是展示窗口，原始数据仍保留。
边界节点的展开按钮只展示已经存在的下游。递归引用停止自动扩展，共享方法的重复子树按需展开。

## 常用动作

详情操作行末尾的 **⋯（更多节点操作）** 与画布右键共用节点菜单，包含添加、隐藏、删除等操作。
方向键选择菜单项，Esc 关闭并将焦点返回入口；根节点的隐藏、删除保持禁用。

| 动作 | 入口与效果 | 是否改写图文件 |
| --- | --- | --- |
| 展开/收起 | 节点末端按钮；节点右键“收起下游” | 否 |
| 从边收起 | 右键连线 → 收起下游；保留箭头指向节点，收起它后面的分支 | 否 |
| 从边隐藏/删除 | 右键连线 → 隐藏或删除；作用于箭头指向的节点及其独占下游，与节点菜单相同 | 隐藏不写入；删除需保存 |
| 隐藏 | 节点右键或详情中的“隐藏”；隐藏该方法及其独占下游 | 否；刷新恢复 |
| 恢复隐藏 | 点击“恢复隐藏” | 否 |
| 删除节点 | 节点右键或详情“删除”，先核对影响范围 | 保存草稿后生效 |
| 添加节点 | 节点右键“添加节点”，选择文件、搜索代码并选中行，校验入口 | 保存草稿后生效 |
| 继续采集 | 任意现存可采源码节点右键或详情“继续采集”，设置深度和新增节点上限后开始 | 采纳/保存后生效 |

收起与隐藏会回收空位；隐藏固定最近可见上游，收起固定操作节点，保持缩放。恢复隐藏时重新分配空间。
节点删除针对源方法的所有调用位置，不只是当前屏幕上的一个路径副本；共享下游按其他调用方的可达性保留。
根节点不能隐藏或减枝。图内节点删除不删除源码文件。

## 工具栏与说明

顶部集中节点搜索、四向导航、居中当前节点、展示设置、源码跳转、语言服务器与采集信息。四向按钮和方向键按屏幕位置选择邻近节点；居中按钮与空格保持当前缩放，将当前节点移到画布中央。
“语言服务器”展开后显示服务器类型、状态与当前可用操作；状态与按钮同行。启动不等于项目索引已全部完成。
节点说明默认展开并限制高度，长内容在说明区阅读；可在详情或节点右键编辑说明，应用后仍需保存草稿。

## 源码核验

右侧预览默认使用侧栏剩余高度，初次内容不足会自动补齐到视口或文件边界。上下“加载更多”每次各增加 20 行；自动换行是本浏览器全局偏好，切换其他节点保持一致。

选中节点查看定义，选中精确调用边查看调用点。使用“打开源码”跳到本地编辑器。
“点击跳转”默认关闭，开启后普通点击节点或精确边触发外部编辑器跳转；展开按钮与拖动不触发。
工具栏“源码编辑器”可选 VS Code 或 IntelliJ IDEA，选择保存在本浏览器。手动打开和点击跳转共用该选择。
浏览器可能需要允许 `vscode://` 或 `idea://` 协议；系统须已安装对应编辑器并注册协议关联。
IDEA 使用 `idea://open?file=...&line=...&column=...`，只使用后端校验返回的位置；未保存节点同样支持。
如果浏览器没有反应，检查系统的协议关联；页面无法检测编辑器是否成功打开，不能把“已请求”当作成功定位。
Windows 的排查、注册和验证步骤见 [IDEA 本机配置](idea-setup.md)。安装 IDEA 不等于已注册 `idea://`。
抽象边、人工关联、多态关系不伪造精确调用行，不能跳转时查看目标定义和关联依据。

节点类型标识依据符号元数据；不能仅凭名称认定接口、实体或运行时实现。
连线 `L<number>` 是源码位置；明确的“顺序”字段也不能自动替代实际运行轨迹。

## 采集与保存

“继续采集”配置框可设置深度 1–100（默认 3）和新增唯一节点上限 1–10000（默认 100），起点为第 0 层，已有节点不计新增。两项可同时设置或分别留空；留空仅解除对应限制，查询预算保护仍存在。显示层数与采集限制相互独立。
开始后工具栏“采集信息”面板显示进度，可请求停止；等待任务状态确认停止，不把按钮点击当作已经终止。
平台同时只允许一个采集任务，新的任务可能被拒绝，不重复提交。

完成后：

- **预览**：在画布查看结果，仍未保存。
- **采纳并保存**：保存整份当前草稿，包含手动添加、删除等其他修改。
- **放弃**：放弃整份草稿，不只放弃这轮新增节点。

手动新增节点可以在未保存的同一草稿中继续采集。草稿在服务内存，不是浏览器持久缓存；重启会丢失，含采集的闲置草稿有过期清理。
站内离开有保存/放弃/取消；刷新和关闭依赖浏览器未保存提醒，不能期待离开时自动异步保存。

## 侧栏与目录

左右侧栏的收起入口位于栏与画布边界。拖动分隔线调宽，方向键微调，双击或 Home 复位；宽度是浏览器偏好。
拖动侧栏时保持画面，结束后同步画布尺寸。工作台手工拖动节点的位置目前不持久保存。

资料库行末“⋯”统一提供新建项目、新建目录、新建图、刷新和折叠。新建项目接入已有源码目录；新建目录是项目内组织调用图的分组，不创建源码目录或任意多级文件夹。项目行末菜单可直接新建目录/图并带入项目；项目、目录、图的重命名和删除集中在各行末尾菜单，回收站行同样使用菜单。

同一项目内可拖动调用图到其他分组或调整顺序；不能以拖动更换源码归属。空分组和目录别名保存到资料库 `.coderova/library.json`；排序及折叠仍是浏览器偏好。
单图“移入回收站”、分组“删除”、最外层目录“删除”会归档图；目录删除包含全部子分组，搜索隐藏的图也包含在内。
确认前读清完整数量，组内未保存修改需先处理。批量操作可能部分失败，检查已归档数量和剩余项。
目录删除不删除项目源码或项目根配置；空目录隐藏偏好保存在本浏览器，恢复/生成调用图后可再次出现。
回收站支持逐图恢复；回收站内再次删除才会永久删除本机图配置文件，源码与布局文件不随之删除。

存储位置与备份方式见[配置与备份](configuration.md)。修改存储位置不自动移动已有文件。

## 问题定位

| 现象 | 先检查 |
| --- | --- |
| 看不到图 | 服务端口、`/api/graphs`、目录搜索条件、回收站、实际 `--graphs` 目录 |
| 不能继续采集 | 是否为当前 LSP 图内的源码节点、是否有运行任务、是否可解析源码；已采过或已有出边不再阻止续采 |
| 没有新增下游 | 请求预算、深度/排除边界、LSP issues、源码版本，不只看画布 |
| 采集结束但文件没变 | 是否只预览而未采纳；检查草稿 dirty |
| 保存失败 | 磁盘图是否被别的任务改动；保留草稿，不自动强制覆盖 |
| 修改后界面仍旧 | 前端是否构建、刷新是否成功、实际打开的服务目录是否正确 |

## 向上调用图

新建图在根节点源码位置确认后选择“向上采集 · 谁调用它”，再创建并设置采集限制。
方向随图保存；从任意源码节点继续采集都沿本图方向，不能在一张图中混用查询完成状态。
向上图的根是追溯起点，不是程序入口；上游在上方（横向布局在左方），箭头保持调用者指向被调用者。
展开、收起、搜索定位、隐藏和删除沿本图探索方向，删除仍先预览且保护根与共享分支。
点击连线核验调用者中的源码。“未发现调用者”不等于没有任何运行时调用者。
首轮不在向上图提供人工添加后续节点；已有说明编辑、源码预览、导航及草稿保存照常使用。
